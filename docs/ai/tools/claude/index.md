# Claude by Anthropic

Claude is the AI model developed and published by **Anthropic**. Anthropic offers 2 different ways to access Claude:

1. Using a subscription (Free, Pro, Max, Team or Enterprise) which gives access to Claude in the chat apps and, on paid plans, to Claude Code. Usage is limited by the plan's usage limits.
2. Using the API (pay as you go) which is billed per token with no fixed usage limits, aside from your own budget. It can be used with Claude Code and with third-party tools like **OpenCode**.

If you want to use Claude as a normal chat-based assistant for day-to-day tasks, a subscription is the easiest and in most scenarios cheapest option. If you need more control over the budget, no plan-based usage limits, or want to use Claude in your own tools and applications, you need API access.


## Licensing

Currently there are 7 different ways to license Claude.

|:------------------|:---------------|:----------|:---------------------|:--------------|
|**Free**|Individual subscription|$0|No|No|
|**Pro**|Individual subscription|$20 per month, or $17 per month billed annually|Yes|No|
|**Max**|Individual subscription|From $100 per month (5x Pro usage), higher tier with 20x Pro usage|Yes|No|
|**Team - Standard seat**|Business subscription|$25 per seat per month, or $20 billed annually|Yes|No|
|**Team - Premium seat**|Business subscription|$125 per seat per month, or $100 billed annually|Yes|No|
|**Enterprise**|Enterprise subscription|$20 per seat per month (billed annually) + usage billed at API rates|Yes|No|
|**API**|Usage-based pricing - pay as you go|Pricing per token usage|Yes|Yes|

!!! info
    Prices are the US list prices at the time of writing and exclude tax. Pricing and currency vary by region and Anthropic can change plans at any time. Check [claude.com/pricing](https://claude.com/pricing) for current prices. Team plans need at least 2 members, Enterprise needs at least 20 seats.

!!! note
    You can use a mix of subscription- and API-based licenses with one person or organization, but be aware that a subscription does not reduce the cost of API usage. The two are billed separately. Enterprise usage is billed at API rates, but this does not give access to the API itself.
