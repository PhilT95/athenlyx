# Plausible - an alternative to Google analytics

Plausible is a privacy-friendly alternative to analytic tools like Google analytics. It works without cookies and only collects basic traffic data and the open-source Community Edition can even be hosted within your own infrastructure. The script that is used to monitor the traffic is lightweight and does not impact the performance of the web application in any noticeable way.

If you want to try out Plausible Analytics yourself you can follow this [setup guide](plausible_setup.md).
