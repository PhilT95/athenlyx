# Infrastructure management

Managing an infrastructure becomes an increasingly complex task with the rapid and constantly changing landscape. Especially with the heavy focus on security you can quickly become overwhelmed by the tasks and duties needed to be fulfilled. The guides & docs provided here aim to relief some that burden by giving access to a solid basis and best practices on managing infrastructure secure and reliant.


## Linux administration

Since Linux is the most common server OS it is crucial to understand how it can be managed, configured, and maintained in a scalable way. Please refer to the [Linux administration docs](linux-admin/index.md) for detailed information and guides.
