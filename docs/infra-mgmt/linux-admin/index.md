# Linux administration

Working in IT or cybersecurity makes the contact with Linux unavoidable. As Linux systems run the worlds infrastructure from web- and application servers to network appliances, most infrastructure components are running some kind of Linux. Being able to work with and manage Linux systems is therefore an increasingly important skill. 

Since Linux is divided into so-called *Distributions* which differ in pre-installed tools, package managers and general system behavior, it is necessary to split the documentation for each Linux distribution.


## Linux distributions

|Distribution|Category|Common use-cases|Article|
|:-----------|:-------|:---------------|:------|
|Red Hat Enterprise Linux (RHEL)|Red Hat family (commercial)|Enterprise servers with vendor support, regulated and compliance-driven environments, SAP, and Oracle workloads||
|AlmaLinux|Red Hat family (RHEL-compatible)|Free RHEL replacement for production servers, web and application hosting, hosting panels|[AlmaLinux Setup](rhel-alma/almalinux_setup.md)|
|Rocky Linux|Red Hat family (RHEL-compatible)|Free RHEL replacement for production servers, HPC and research clusters, general enterprise workloads||

|Debian|Debian family|Stable long-running servers, container base images, network, and infrastructure services||
|SUSE Linux Enterprise Server (SLES)|SUSE family (commercial)|SAP workloads, enterprise data centers, mission-critical systems with vendor support||
