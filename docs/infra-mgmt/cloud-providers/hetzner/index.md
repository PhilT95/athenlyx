# Hetzner Online GmbH

Hetzner is a data center and cloud provider based in Germany. Since its founding in 1997 has become well-known for its rather simple, cost-effective hosting options. Its services lack a lot of features you'd expect from a bigger cloud provider like STACKIT (as a European alternative), but especially with their rather new and expanding private networking feature it is a realistic alternative for small to mid-sized companies as well as private projects.

Besides its presence within the EU Hetzner also offers hosting options outside of Europe, for example in the US or Singapore.

## Services

Hetzner offers a variety of services:

- Cloud servers with shared or dedicated vCPUs
- Object Storage and Storage boxes
- Managed web hosting, storage and entire servers that can be rented

The managed services are not directly connectable to the dedicated and shared hosting options which are your normal VM hosting options. With additional services for these VMs like private networking, private DNS, backups and more Hetzner provides all the basic needs to set up your own environment. If you need advanced features like a Kubernetes cluster, you either have to build it yourself on top of their services or switch to another hosting alternative.
